常見問題

五個最常遇到的狀況

Hiddify 是什麼？需要付費嗎？

Hiddify 是開源免費的代理客戶端，無廣告。App 本身免費，你只需要一條有效的訂閱連結即可使用。

如何把訂閱匯入 App？

用帶有 ?sub= 參數的專屬網址開啟本頁，點「一鍵匯入 Hiddify」，在跳轉提示中確認開啟，即可自動完成匯入。

中國大陸 Apple ID 搜尋不到 Hiddify？

大陸區 App Store 未上架。請切換至美區或海外 Apple ID 後，點擊本頁的 App Store 連結下載；Android / Windows / Mac 可改用官網直載。

首次連線要求「加入 VPN 配置」？

這是系統的正常授權流程。點「允許」，並以螢幕密碼或 Face ID 確認，Hiddify 會建立配置並開始連線。

連上後部分網站打不開？

請確認 App 內的路由模式已切換為 Global（全局），讓全部流量經過代理，然後斷開重連一次即可。
