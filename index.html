計時規則 如果我在出發前就匯入，天數會立刻開始倒數嗎？ +

不會！我們採用業界最人性化的「首次連線才啟動（Start on First Use）」機制。

在台灣或出發前提前將訂閱匯入 App，帳號皆處於安全待機狀態（天數不倒數）。只有當您抵達目的地並第一次點擊連線按鈕時，伺服器才會正式開始計算天數，請放心提前在出發前配置完畢。

續費加量 流量用完或天數到期怎麼辦？如何續費？ +

若在旅途中流量用盡或天數不足，隨時聯絡管理員私人轉帳即可線上無感「續杯」。

管理員在後台完成加購後，您完全不需要重新設定或更換連結。只需打開 Hiddify 首頁在螢幕頂部輕輕下拉刷新（Pull to Refresh），流量進度條即刻恢復，連線秒級自動恢復正常。

線路品質 連線速度與品質如何？什麼是「三網優化 VPS」？ +

我們的伺服器架設於美西企業級專用 VPS，直連中國電信 CN2 GIA、中國聯通 9929/AS4837 與中國移動 CMIN2 三大運營商最高等級之直連專線。

一般便宜節點在晚高峰（20:00 - 24:00）丟包率高達 30%~50%，而三網優化線路享有電信級的最高優先級 QoS 佇列保障（單人保障 50Mbps 獨立通道），幾乎零丟包，無論是 YouTube 4K 即點即播、視訊會議或低延遲工作皆全天候順暢。

隱私保障 服務如何保障用戶隱私？是否有連線日誌？ +

堅持 100% 嚴格零日誌（Zero-Log）政策：

節點完全由我們自主管理與維護，不依賴任何第三方商業 VPN 公司，後端徹底關閉訪問日誌與連接記錄；我們絕不收集、記錄或分析您的任何瀏覽歷程、DNS 查詢與傳輸數據。

通訊安全 使用什麼通訊協定？如何防止被阻斷或窺探？ +

全線採用目前最強大的 VLESS-Reality 協定與 TLS 1.3 / X25519 前向保密端對端加密。

此架構將代理傳輸特徵深度偽裝為常規大型網站（如 Cloudflare）的合規 HTTPS 流量，在傳輸鏈路上徹底杜絕中間運營商的深度封包檢測（DPI）與主動探測，保證連線隱形且極度抗干擾。

客戶端安裝 在 App Store 搜尋不到 Hiddify 該如何處理？ +

因受區域政策限制，大陸地區 Apple ID 暫未上架海外代理工具。

解決方案：只需在 App Store 退出大陸帳號，登入任意海外地區 Apple ID（美區、日區、港區或台區），再點擊本頁面的 App Store 下載按鈕即可順利安裝。安裝完畢後可隨時換回原帳號，不影響日常使用。

客戶端安裝 Windows 或 Mac 安裝時出現「未受信任 / SmartScreen 攔截」？ +

這是由於開源社群軟體未向微軟或蘋果支付高額商業代碼簽名費用的正常提示，軟體原始碼完全公開且經安全審計：

• Windows 用戶：點擊提示視窗上的「其他資訊」或「詳細資訊」，再點擊「仍要執行」即可。

• macOS 用戶：前往「系統設定」→「隱私權與安全性」→ 滑動至頁面最下方點擊「強制打開」即可。

系統授權 首次點擊連線時，手機提示「加入 VPN 配置」是否安全？ +

完全安全。這是 iOS、Android、macOS 系統在建立本機加密虛擬網卡（TUN 模式）時的標準系統安全防護機制。

請點擊「允許」並輸入手機解鎖密碼或 Face ID 授權，所有數據均在本地加密後直接出境，不經過任何第三方中轉。

使用指引 在 App 內應該選擇「規則分流」還是「全局代理」？ +

強烈建議保持預設的「規則分流（Rule）」模式。

在規則模式下，微信、淘寶、小紅書、台灣網銀等境內正常服務自動直連，不消耗專線流量且速度最快；Google、YouTube、Instagram、Line、海外工作系統自動由專線加速。若遇極少數冷門外國網站打不開時，再手動切換至「全局（Global）」。

註：為保障全體用戶之 IP 純淨與合規安全，伺服器全面阻斷 BitTorrent (BT) P2P 下載及郵件發信連接埠。
