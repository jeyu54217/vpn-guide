常見問題

大白話版 · 四個最常遇到的狀況
中國大陸 Apple ID 搜尋不到 Hiddify？

大陸區 App Store 沒有上架。先把 Apple ID 切到美區 / 海外 / 台灣區再點上方下載鈕；或改走 GitHub Releases 官方載點。

第一次連線跳「加入 VPN 配置」？

這是 iOS / macOS 的正常系統授權。點「允許」，輸入螢幕密碼或用 Face ID 確認，Hiddify 就會建好配置並連線。

去哪看剩餘流量和到期天數？

匯入訂閱後，打開 Hiddify 的訂閱頁 / 首頁資訊列就會顯示剩餘流量條與到期天數；流量快用完或快到期請提前續費。

連上了但某些網站打不開？

確認 Hiddify 已切到 Global（全局）模式而不是自動 / 規則模式，讓全部流量走代理，再斷開重連一次。
